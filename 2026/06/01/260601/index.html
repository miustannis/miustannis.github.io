最近在捣鼓扩散模型，参照HuggingFace的教程，搭了一个 MiniU-Net 跑了一遍训练

项目简述

项目目标：让模型学会把一张加了噪声的手写数字恢复到干净状态

Diffusers/
├── BasicUnet.py            # MiniU-Net，~50K 参数
├── diffusion_learning.py   # 训练 + 简化的去噪采样
└── diffusers_usage.py      # HuggingFace Diffusers 库的配置示例

用 MNIST 的 28×28 灰度数字图，往上面随机加噪声，然后训练一个 U-Net 把噪声去掉。降噪任务就是扩散模型一开始提出时的核心，后续推广到生成与多模态领域。

DDPM：生成模型的核心原理

DDPM 的核心逻辑是前向反复加噪，逆向逐步去噪

DDPM（Denoising Diffusion Probabilistic Models）是 Ho 等人在 2020 年提出的，它把上面这个过程变成了两条马尔可夫链：

前向：x₀ → x₁ → x₂ → ... → x_T    （真图 → 纯噪）
逆向：x_T → x_{T-1} → ... → x₀    （纯噪 → 新图）

前向是固定的（不需要学习），逆向才是模型要学的。

前向扩散

一步一加

每一步我们做同样的事情——保留一部分原图信号，再拌入一部分噪声：

$q(x_t | x_{t-1}) = \mathcal{N}\big(x_t;\ \sqrt{1-\beta_t} \cdot x_{t-1},\ \beta_t \mathbf{I}\big)$

$\beta_t$ 是一个很小的数，从 $10^{-4}$ 慢慢涨到 $0.02$。一开始噪声加得很克制，到后面几乎全是噪声，把最后的结果看作正态分布的噪声

合并步数

因为正态分布的性质比较优雅，这 1000 步可以被”折叠”成一步：

定义 $\alpha_t = 1 - \beta_t$，$\bar{\alpha}_t = \alpha_1 \cdot \alpha_2 \cdots \alpha_t$，那么：

$$x_t = \sqrt{\bar{\alpha}_t} \cdot x_0 + \sqrt{1 - \bar{\alpha}_t} \cdot \epsilon,\qquad \epsilon \sim \mathcal{N}(0, \mathbf{I})$$

这是整篇文章中比较重要的公式。(除了另外几个算 Lower Bound 与KL散度的公式之外) 它的意思就是：不管时间步 t 是多少，我可以直接从原始图 $x_0$ 算出 $x_t$，不需要迭代。

代码里做了简化——随机选一个噪声量 amount，直接线性混合：

def corrupt(x, amount):
    noise = torch.rand_like(x)
    amount = amount.view(-1, 1, 1, 1)
    return x * (1 - amount) + noise * amount

式中：amount=0 → 原图，amount=1 → 纯噪声，中间就是各种程度的模糊。

逆向去噪

逆向过程才是需要训练的。我们用神经网络 $\epsilon_\theta$ 来猜：给定 $x_t$ 和时间步 $t$，$x_t$ 里面混了多少噪声

$$p_\theta(x_{t-1} | x_t) = \mathcal{N}\big(x_{t-1};\ \mu_\theta(x_t, t),\ \sigma_t^2 \mathbf{I}\big)$$

为什么让模型预测”噪声”而不是”干净图”

  • 如果让模型直接预测 $x_0$非常难做
  • 如果让模型预测噪声 $\epsilon$——噪声的分布是 $\mathcal{N}(0, I)$，零均值、单位方差，相对更规矩

预测噪声更好，因为：

  1. 目标分布简单：在全局假设中，不管输入是什么，噪声永远服从同一个分布
  2. 等价可转换：知道了噪声 $\hat{\epsilon}$，就能反推出 $\mu_\theta$，进而得到 $x_{t-1}$
  3. 实践验证：大量实验表明预测噪声的训练更稳定、生成质量更高

本项目做的是简化版——直接预测 $x_0$，方便理解。其中代码上差别没那么大

训练

DDPM 的训练循环，论文中并没有全部采样时间步：

  1. 拿一张干净图 $x_0$
  2. 随机挑一个时间步 $t$
  3. 随机生成噪声 $\epsilon$
  4. 一步算出 $x_t = \sqrt{\bar{\alpha}_t} \cdot x_0 + \sqrt{1 - \bar{\alpha}_t} \cdot \epsilon$
  5. 让模型根据 $x_t$ 猜噪声 $\hat{\epsilon}$
  6. 算 MSE：$\mathcal{L} = |\epsilon - \hat{\epsilon}|^2$
  7. 反向传播，更新参数

在项目中，对应的代码更直观——模型直接预测干净图，和原图算 MSE：

noise_amount = torch.rand(x.shape[0]).to(device)   # 随机噪声量
noisy_x = corrupt(x, noise_amount)                  # 加噪
pred = net(noisy_x)                                  # 模型预测干净图
loss = loss_fn(pred, x)                              # 和真图比 MSE

采样/生成

生成新图时，从一个纯噪声 $x_T$ 开始，一步步去噪：

$x_{t-1} = \frac{1}{\sqrt{\alpha_t}} \left(x_t - \frac{1 - \alpha_t}{\sqrt{1 - \bar{\alpha}_t}} \cdot \epsilon_\theta(x_t, t)\right) + \sigma_t \cdot z$

最后加的那个 $\sigma_t \cdot z$ 是随机噪声，保证生成的多样性, 但在简化版里我直接省略了，保持每一步都是确定性的

项目中简化为 5 步线性插值：

n_steps = 5
x = torch.rand(8, 1, 28, 28)   # 从纯随机噪声开始
for i in range(n_steps):
    pred = net(x)                # 模型猜干净图
    mix_factor = 1 / (n_steps - i)  # 这一步迈向预测结果的比例
    x = x * (1 - mix_factor) + pred * mix_factor

每步往模型预测的干净图方向挪一点，5步后就能看到有一些样子的数字了

网络结构

扩散模型的经典backbone是U-Net，
这里用的MiniU-Net 结构更简明：

Input (1, 28, 28)
  │
  ├─ Conv(1→32) → SiLU ──→ [保存 skip] → MaxPool (14×14)
  ├─ Conv(32→64) → SiLU ──→ [保存 skip] → MaxPool (7×7)
  └─ Conv(64→64) → SiLU
                      │
  ┌─ Upsample → + skip ─→ Conv(64→64) → SiLU
  ├─ Upsample → + skip ─→ Conv(64→32) → SiLU
  └─ Conv(32→1)
                      │
               Output (1, 28, 28)

其中：

  • 下采样：MaxPool2d 逐步把空间尺寸从 28→14→7，同时通道数从 1 升到 64
  • 跳跃连接：下采样途中把中间特征存起来，上采样时拼回去——这样模型不会”忘记”边缘和细节
  • 上采样：Upsample 把尺寸恢复回来，配合跳跃连接逐步重建
  • 激活函数：全用 SiLU（Swish），比 ReLU 在生成任务上表现更丝滑

公式速查

符号 含义
$x_0$ 原始干净图像
$x_t$ 第 t 步加噪结果
$x_T$ 纯噪声（标准 DDPM 取 T=1000）
$\beta_t$ 第 t 步噪声方差，从小到大（如 $10^{-4} \to 0.02$）
$\alpha_t$ $1 - \beta_t$
$\bar{\alpha}_t$ $\prod_{s=1}^t \alpha_s$
$\epsilon$ 标准高斯噪声 $\sim \mathcal{N}(0, I)$
$\epsilon_\theta$ 神经网络（U-Net），输入 $x_t$ 输出预测的噪声

前向扩散（一步到位）：

$x_t = \sqrt{\bar{\alpha}_t} \cdot x_0 + \sqrt{1 - \bar{\alpha}_t} \cdot \epsilon$

逆向采样：

$x_{t-1} = \frac{1}{\sqrt{\alpha_t}} \left(x_t - \frac{1 - \alpha_t}{\sqrt{1 - \bar{\alpha}_t}} \cdot \epsilon_\theta(x_t, t)\right) + \sigma_t z$

训练 Loss：

$\mathcal{L} = \big|\epsilon - \epsilon_\theta(x_t, t)\big|^2$

和标准DDPM的对比

本项目 标准 DDPM
预测目标 干净图 $x_0$ 噪声 $\epsilon$
噪声调度 随机均匀采样 amount 线性 $\beta_t$ 调度表（1000 步）
采样步数 5 步线性插值 1000 步马尔可夫链
U-Net 简易版，无 attention，无时间嵌入 完整版，含 attention + time embedding

DDPM 之后

DDPM 打开了局面，但它有一个明显的痛点——生成一张图要迭代很多步，太慢了。因此后续的研究基本都在解决这个问题：

  • DDIM（2020）：去掉马尔可夫约束，采样步数从 1000 砍到 50~100 步，质量几乎不降
  • Stable Diffusion / Latent Diffusion（2022）：不在像素空间扩散，改在 VAE 压缩后的潜空间——计算量骤降，让扩散模型能跑在消费级 GPU 上
  • DPM-Solver / DPM++（2022）：用 ODE 数值求解器替代随机采样，20~50 步达到高质量
  • Consistency Models（2023）：训练模型一步或两步就能生成，直接对标 GAN 的速度

现在在 Civitai 上下载的 Stable Diffusion 模型、Midjourney 的 V6、OpenAI 的 DALL·E 3——它们的技术底座都能追溯到 DDPM 这篇 2020 年的论文。
